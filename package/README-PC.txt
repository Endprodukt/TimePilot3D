Time Pilot 3D - PC version
==========================

By Oliver Carell (Endprodukt)

Start: double-click timepilot3d.exe (full screen), or run
"timepilot3d.exe --windowed" from a command prompt (in a window).
On the first start the game asks what it is played with (yoke, or
joystick and buttons) - choose with the arrow keys, confirm with 1.

Keys
  Arrow keys      steer (up = nose down, as with a yoke)
  Left Ctrl       fire
  Left Alt        faster
  Space           slower
  Left Shift      look back
  5               insert a coin
  1               start; in a game: change the view (HUD, cockpit, chase)
  F2 or Tab       service menu (settings); the game starts again after it
  Esc             quit

A joystick or gamepad works too; the game asks for its buttons on the
first start (or later in the service menu, under CONTROLS).

Settings and high scores are kept in the "save" folder next to the
program. To reset everything: F2, FACTORY RESET AND RESTART, press 1 twice.
