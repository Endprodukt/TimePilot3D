Time Pilot 3D
=============

By Oliver Carell (Endprodukt)

Time Pilot as a 3D vector game for the VectorPie cabinet.

To install: put the .vpk package on a USB stick, then in the cabinet's
menu go to Settings, GAMES, INSTALL FROM USB.

Service menu (settings): F2 or Tab. When it is closed, the game starts
again.
